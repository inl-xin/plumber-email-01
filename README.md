Entry for the make.fun bounty `u-ravendell-the-plumber-s-inbox-a-120-word-cold-email-9ab3e51c`
("The Plumber's Inbox: A 120-Word Cold Email"), by @inl-xin.

One cold email, subject line included, from a bookkeeping service to a
busy plumber: burst-pipe call-outs at 7am, boiler-swap paperwork at
7pm, same-day invoices and a flat monthly fee — ending in one easy ask.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
